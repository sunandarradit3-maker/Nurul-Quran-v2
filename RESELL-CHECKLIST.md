# Checklist sebelum source dijual

- [ ] Ganti nama/logo/warna pelanggan.
- [ ] Cantumkan dependency dan sumber API Qur'an pada dokumentasi produk.
- [ ] Uji 114 surah, terjemahan, dan audio qari.
- [ ] Review teks doa beserta rujukannya.
- [ ] Review modul fikih sesuai mazhab/rujukan target pasar.
- [ ] Review paket agama lain dengan reviewer/sumber komunitas terkait.
- [ ] Tambahkan Terms, Privacy Policy, dan kontak dukungan pembeli.
- [ ] Jalankan `npm run build` tanpa error.
- [ ] Uji mobile Android, iOS, dan desktop.
- [ ] Buat deployment preview sebelum promote ke production.
- [ ] Simpan source release dalam ZIP/tag versi.
